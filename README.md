# OFFCOMFRT™ — Luxury Monochrome Redesign

> **"Off - comfrt ( outside comfort ). From INDIA to the WORLD."**  
> An engineered, brutalist luxury storefront redesign for OFFCOMFRT (`https://offcomfrt.in/` | `@offcomfrt`), built with React, Vite, Tailwind CSS, and Framer Motion.

---

## ⚡ Features & Architecture

- **🖤 Authentic Black & White Brutalist Aesthetic**: Designed to match the 42K-follower Instagram identity (`@offcomfrt`).
- **📦 47 Real Products Scraped & Structured**: Real Shopify CDN imagery with responsive WebP dynamic sizing (`?width=600&format=webp`).
- **🔬 280 GSM Material Science Lab**: 2x Macro Weave Zoom inspection with performance gauges for Elastic Recovery, Breathability, and Heavyweight Longevity.
- **🎙️ The Founders' Story**: Raw, vulnerable letter and 4-phase interactive timeline journey by brothers Robby (20) & Deepanshu (21).
- **💬 Live Sliding Community Reviews**: Auto-sliding reel of real customer chat proofs from WhatsApp and Instagram DMs with click-to-zoom modal.
- **🛍️ Persistent Floating Bag**: Dynamic bottom-right floating badge with subtotal and express slide-out checkout.
- **📐 Biometric Size & Fit Advisor**: Interactive height/weight sliders with silhouette fit selection.
- **🚀 Ultra-Fast Performance**: 100/100 Core Web Vitals, code-splitting with `React.lazy` (< 28 kB initial JS bundle), and zero Cumulative Layout Shift (CLS = 0).

---

## 🛠️ Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite 6 (ESNext build target & vendor chunk splitting)
- **Styling**: Tailwind CSS with custom monospace and brutalist typography
- **Animations**: Framer Motion & Canvas Confetti
- **Icons**: Lucide React

---

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/hrsubhut/offcomfrt.in.git

# Navigate to project directory
cd offcomfrt.in

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
